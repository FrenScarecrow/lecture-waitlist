# Story 2.3：补位幂等与重复触发防护

**作为** 系统，
**我希望** 同一空位只补一位候补者、重复触发不二次补位，
**以便** 在重复请求、并发取消多个名额、取消与扩容同时发生时仍不双占。

## 验收标准

1. 对同一空位并发/重复触发补位，最终只有一位候补者被补入（FR-9）。
2. 补位记录与日志一一对应，无重复补位条目（FR-9）。
3. 多个名额同时释放时，按顺序一对一补位，不重不漏（FR-9）。
4. 补位删除校验影响行数：`DELETE … WHERE id = ? AND lecture_id = ?` 影响行数为 0 时，不执行 `INSERT registration`，直接返回（规则 18）。
5. 幂等 AC：对同一空位重复触发补位两次（模拟重复请求或重试），断言只产生一条补位记录、只有一位候补者被补入（规则 19）。
6. 唯一约束 `UNIQUE(lecture_id, student_id)` 作为「不双占」的最后防线兜底（ADR-004，规则 9）。
