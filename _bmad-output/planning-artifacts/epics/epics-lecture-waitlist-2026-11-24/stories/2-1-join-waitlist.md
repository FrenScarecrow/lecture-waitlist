# Story 2.1：满员提示与主动加入候补

**作为** 学生，
**我希望** 报名满员讲座时被提示满员、并能主动选择加入候补拿到顺序号，
**以便** 在有人取消时按先来后到自动补入。

## 验收标准

1. 满员讲座报名被拒后，显示「加入候补」选项；学生确认后进入候补并拿到顺序号（FR-7）。
2. 顺序号按加入候补时间递增，对学生可见（FR-7，ADR-007，规则 12）。
3. 同一学生对同一讲座不重复加入候补，重复返回 `DUPLICATE_WAITLIST`（409）（FR-7，规则 8）。
4. 报名窗口外（报名开始前/截止后）不可加入候补（FR-7）。
5. 未加入候补者不在候补队列中，后续扩容/补位不涉及（FR-7）。
6. 加入候补写事务第一步 `SELECT … FOR UPDATE` 锁 `lecture` 行（ADR-005，规则 3/17）。
7. 顺序号读时用 `ROW_NUMBER()` 计算，不落库；排序键为复合键 `(cohort, sort_ts)`，正常加入 `sort_ts = joined_at`、`cohort = 'normal'`（ADR-007，规则 12）。
