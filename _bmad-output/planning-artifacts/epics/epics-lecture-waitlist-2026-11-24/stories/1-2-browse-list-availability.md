# Story 1.2：浏览列表与实时余量

**作为** 学生，
**我希望** 浏览未结束讲座列表并实时看到每场的剩余名额与状态，
**以便** 决定报名哪一场，避免满员讲座白跑。

## 验收标准

1. 学生登录后可浏览未结束讲座列表，每场显示「剩余 N 人」；N 由 `COUNT(*)` 报名数对 `capacity` 派生，N=0 时显示「已满」（FR-4，规则 6）。
2. 报名未开始（当前时间早于报名开始时间）的讲座显示「报名未开始 / X 点开放」且不可报名（FR-4）。
3. 已结束讲座不进入报名列表，或明确标记为已结束、不可报名（FR-4）。
4. 讲座状态（已发布/已开始/已结束）按当前时间对 `start_at`/`end_at` 读时派生，不落 status 列（ADR-011）。
5. 报名数变化后，余量在页面刷新/下次读取时反映最新值（FR-4）。
6. 列表与状态展示时区在展示层转 Asia/Shanghai（规则 7）。
